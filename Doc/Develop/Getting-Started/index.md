
# Getting Started

## Requirements

| Dependency | Version |
| :--- | :--- |
| Minecraft | 26.1.2 (Snapshot 11) |
| Fabric Loader | ≥ 0.18.4 |
| Fabric API | 0.142.1+26.1 |
| DasikLibrary | 1.6.9+build.15 |
| Java | 25 |

## Building from Source

```bash
git clone <repo-url>
cd agrarian-reform
./gradlew build
```
